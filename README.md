## 🍿**TheMovieBrowser.com**

**[The Movie Browser](https://themoviebrowser.com)** is built to enhance the way you explore and interact with movies and TV shows. Some key features include:

- **Watch Links**: Quickly find where your favorite movies are streaming, a one stop place to aggregate every streaming provider.

- **Ratings**: Get ratings from all the major sources in one place.

- **Intelligent Recommendations:** get AI powered recommendations backed by embeddings and vector search

- **Powerful custom filters:** create powerful custom filters to suit very specific needs, you can create a [filter to just see comedy war movies that are streaming on prime video](https://themoviebrowser.com/browse?genres=35,10752&providers=10,9) or [post-apocalyptic movies](https://themoviebrowser.com/browse?keywords=4458&exclude_genres=16&min_rating=5&min_votes=10) if youre into that

- **Watchlists and episode tracking:** keep track of what you want to watch and where you are in a series

Built with Next.js, TypeScript, PostgreSQL + pgvector, LangGraph and AWS Bedrock. Source: [ChaitanyaVootla/movie-browser](https://github.com/ChaitanyaVootla/movie-browser)
